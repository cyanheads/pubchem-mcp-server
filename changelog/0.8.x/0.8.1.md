# 0.8.1 — 2026-11-10

## Added

- **`content[]` reads back as `structuredContent`** ([#88](https://github.com/cyanheads/pubchem-mcp-server/issues/88)) — values an agent may send back (identifiers, SMILES, InChI, InChIKey, formulas, names, synonyms, accessions, xref and conformer IDs) render as code spans, or fenced blocks when they hold a line break. Other upstream text is Markdown-escaped, and quoted prose is escaped and quoted. Raw SDF keeps its final newline. On `pubchem_get_compound_details` the compound name moves out of the `## CID n` heading and MeSH and ATC entries are list items; `pubchem_get_summary` row headers read `**Identifier found:** …` and `**Identifier not found:** …`.
- **`pubchem_search_compounds` identifier mode reads `query`** ([#90](https://github.com/cyanheads/pubchem-mcp-server/issues/90)) — a non-blank `query` sent without `identifiers` is read as `identifiers[0]`, with a notice. `missing_identifier_args` names it in its hint when `identifierType` is missing.
- **`cid` on `pubchem_get_compound_details` and `pubchem_get_compound_safety`** ([#91](https://github.com/cyanheads/pubchem-mcp-server/issues/91)) — `cid` is accepted for `cids`, along with a lone CID and numeric strings.
- **`SMILES` and `ConnectivitySMILES` in `properties`** ([#92](https://github.com/cyanheads/pubchem-mcp-server/issues/92)) — on `pubchem_get_compound_details` and `pubchem_search_compounds`, returned as `IsomericSMILES` and `CanonicalSMILES`. A property named twice is requested once.

## Changed

- **Aborted PubChem requests** — a request aborted by something other than the caller is retried once before failing (mcp-ts-core 0.13.22).
- **`engines.bun`** — `>=1.4.0` → `>=1.4.4`.

## Fixed

- **`pubchem_get_compound_details` with `properties: []`** — returns the default core set. It reported every CID not found and sent no request.
- **`pubchem_get_compound_details` labels** — the canonical SMILES reads `**Canonical SMILES:**`, and Title renders beside IUPAC Name.
- **`pubchem_get_summary` description quote** — no longer absorbs the field line after it.
- **`pubchem_get_compound_3d_structure` `format: "sdf"`** — a record of exactly 500 lines was capped, losing its final newline under a cap notice.
- **Fenced-block rendering on Node** — holds for any text length.
