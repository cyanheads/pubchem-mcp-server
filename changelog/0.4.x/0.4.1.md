# 0.4.1 — 2026-07-03

## Changed

- **`pubchem_get_compound_safety`** — precautionary (P-code) statements now decode to standard UN GHS Rev. 10 Annex 3 text via a new `PRECAUTIONARY_STATEMENTS` table (mirrors the existing `PICTOGRAM_LABELS` pattern); `statement` was previously always `""`. Codes with no Rev. 10 text (free-fill placeholders, deleted codes) still fall back to `""`. ([#31](https://github.com/cyanheads/pubchem-mcp-server/issues/31))
- **`pubchem_get_compound_interactions`** — target-kind activity values now carry the asserted `uM` unit (e.g. `"Ki = 0.0005 uM"`), grounded in PubChem's documented micromolar deposit convention; previously unitless. ([#32](https://github.com/cyanheads/pubchem-mcp-server/issues/32))
