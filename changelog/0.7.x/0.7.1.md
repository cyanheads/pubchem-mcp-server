# 0.7.1 — 2026-10-24

## Added

- **`pubchem_get_compound_xrefs` `CAS` and `EC` types** ([#77](https://github.com/cyanheads/pubchem-mcp-server/issues/77)) — the numbers deposited for the compound, from PUG View, most-attested first. `sourceCounts` counts source records per ID. `RN` is unchanged and remains PubChem's unranked registry-number list.
- **`failedTypes`** on `pubchem_get_compound_xrefs` and `pubchem://compound/{cid}/xrefs` ([#77](https://github.com/cyanheads/pubchem-mcp-server/issues/77)) — a type that fails to load is named while the others return. The resource's default set now includes `CAS`.
- **`pubchem_search_compounds` `identifierType: "inchi"`** ([#80](https://github.com/cyanheads/pubchem-mcp-server/issues/80)) — resolves full InChI strings.
- **`pubchem_get_bioactivity` `assayType`** ([#79](https://github.com/cyanheads/pubchem-mcp-server/issues/79)) — each assay carries `assayType` and `pmids` (also on `pubchem://compound/{cid}/bioactivity`); the new `assayType` filter narrows by type and combines with the outcome and target filters.

## Changed

- **`pubchem_get_compound_interactions` defaults to `kinds: ["drug-food"]`** ([#78](https://github.com/cyanheads/pubchem-mcp-server/issues/78)) — `drug-drug` comes from an SDQ service that refuses automated requests, so it now lands in `failedKinds` only when asked for.
- **`pubchem_get_compound_interactions` `target` kind is rebuilt from the compound's assay summary** ([#78](https://github.com/cyanheads/pubchem-mcp-server/issues/78)) — one entry per target with assay counts by outcome and the most potent active value, gene and protein names attached on a best-effort basis. `paging[].totalRecords` counts targets for this kind.
- **`pubchem_search_compounds` paging** ([#76](https://github.com/cyanheads/pubchem-mcp-server/issues/76)) — identifier and assay modes page past offset 10000. Bounded modes fail as `offset_ceiling_exceeded` above it, and the page that reaches the ceiling omits `nextOffset` and states how far `offset=10000` still reaches.
- **`pubchem_get_summary` identifier range** ([#74](https://github.com/cyanheads/pubchem-mcp-server/issues/74)) — pieces above 2147483647 are marked invalid without a request, and a call whose every piece is unusable fails as `invalid_identifier`.
- **Caller text echoed into notices and errors** ([#74](https://github.com/cyanheads/pubchem-mcp-server/issues/74)) — framed on one line and cut to 100 characters.
- **`pubchem_get_compound_xrefs` empty `ProteinGI` result** ([#72](https://github.com/cyanheads/pubchem-mcp-server/issues/72)) — says PubChem serves no ProteinGI data instead of asking the caller to verify the CID.

## Fixed

- **A markup-only string entry in an ATC or GHS record** no longer breaks `pubchem_get_compound_details` or safety parsing.

## Security

- Rendering caller text in notices and the markdown trailer now runs in time linear in its length.
