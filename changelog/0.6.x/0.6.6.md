# 0.6.6 — 2026-10-07

## Changed

- **`@cyanheads/mcp-ts-core` ^0.13.6 → ^0.13.13** — error results end `content[]` with `request <id>` and carry `data.requestId`, and a declared `recovery` hint reaches every matching failure without per-call forwarding (0.13.10); an integer sent for a string argument is repaired before validation (0.13.9); stack traces, request context, and `data.rootCause` no longer reach client error data (0.13.7, 0.13.8, 0.13.13); `ctx.log`'s client mirror honors `MCP_LOG_LEVEL` and masks sensitive fields (0.13.11); `@modelcontextprotocol/server` 2.0.0 → 2.2.0 (0.13.9, 0.13.11).
- **Typed not-found on `pubchem://compound/{cid}` and `pubchem://assay/{aid}`** — failures carry `data.reason` (`cid_not_found` / `aid_not_found`) and a recovery hint; code and message are unchanged (-32001). `pubchem://compound/{cid}/image` declares the `cid_not_found` its client already raised.
- **`pubchem_get_compound_3d_structure`'s `no_3d_structure` contract states PubChem's 404 covers both a compound with no 3D conformer and a CID with no record**, and its recovery hint covers both.
- **`pubchem_search_assays`'s `invalid_geneid_query` `when` reads "contains characters other than digits"**, matching the digits-only check.
- **Recovery hints come from the declared error contracts** — `ctx.recoveryFor` spreads and the hints `PubChemClient` attached to `cid_not_found` and `no_3d_structure` are removed.
- **Docker image** installs production dependencies in a `deps` stage on the build platform, cross-installing for the target, with `scripts/install-otel.ts` adding the OpenTelemetry peers and `scripts/prune-musl-packages.ts` removing musl-only packages; the image no longer sets `MCP_FORCE_CONSOLE_LOGGING`.
- **`package.json` scripts** run through `bun run`, `start` runs `node dist/index.js`, `start:stdio` sets `MCP_TRANSPORT_TYPE=stdio`, and `files` excludes `dist/*.mcpb`.
- **Maintenance resync** — `framework-skills/`, the devcheck, lint, and release scripts (`lint:packaging` checks the Dockerfile build platform and `server.json` launch shape; `release:github --check` validates the tag annotation), `.gitignore`/`.dockerignore` ignore every `.env*` file except the templates, `.mcpbignore`, the CodeQL workflow (one job per language), `.env.example`, and `CLAUDE.md`/`AGENTS.md`/`README.md`.
- **`.env.example`** lists `LOG_TOOL_FAILURE_PAYLOADS`, `LOG_TOOL_FAILURE_PAYLOAD_MAX_BYTES`, and the traces, metrics, and opt-in logs OTLP endpoint variables as commented-out framework options.

## Fixed

- **`server.json` HTTP entry starts the HTTP transport** — the npm entries drop the `run start:*` package arguments (the package bin ignores them, so the HTTP entry started stdio) and use `runtimeHint: "npx"`; the streamable-http entry sets `MCP_TRANSPORT_TYPE` to `http`.
