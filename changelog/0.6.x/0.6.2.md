# 0.6.2 — 2026-09-13

## Changed

- **HTTP deployments default to stateless sessions** in the published server metadata and example configuration; PubChem tools do not require multi-request session state.
- **Framework development skills moved to `framework-skills/`** with package checks, contributor links, and generated tree documentation updated for the new location.
- **Empty and whole-value placeholder environment variables now resolve as unset** through `@cyanheads/mcp-ts-core`, so optional values remain absent and defaulted values use their schema defaults.
- **Invalid tool arguments return a structured `InvalidParams` error** through the framework's current JSON-RPC error path.
- **Project metadata and local gates track the current framework templates**, including plugin validation, issue forms, Bun 1.4 support, and Vitest 5.

## Fixed

- **PubChem HTTP retries honor framework retry classification**: an upstream 500 retries once, while a 501 marked `retryable: false` fails immediately.
